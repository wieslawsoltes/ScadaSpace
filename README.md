# ScadaSpace

An independent, modular industrial visualization and SCADA workbench built with C#, Uno Platform and Skia GPU rendering for desktop and WebAssembly.

## Status

Implementation in progress. **Not a drop-in replacement for Ignition Perspective, not full feature parity, and not validated for control of live industrial equipment.** The browser demonstration uses an isolated simulated plant. Ignition and Perspective are trademarks of Inductive Automation; this project is unaffiliated and does not redistribute their software or assets.

The implementation separates project models, expressions, tags, history, alarms, runtime bindings, rendering, reusable controls, designer services, and the application. Features and validation results will be tracked in `docs/parity.md` and `docs/validation.md`.
